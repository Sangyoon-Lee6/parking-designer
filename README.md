# 주차장 개략 설계

아파트 지하주차장 평면을 조건, 평면 확정, 결과(3D·평면도) 세 단계로 검토하는 웹앱입니다. 인허가 도면이 아니라 개략 검토용입니다. 실제 심의는 해당 지자체 조례와 최신 법령을 확인해야 합니다.

## 법령 (확인 2026-11-07)

- [주택건설기준 등에 관한 규정 제27조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1026910127) — 공동주택 주차대수. 시행 2026. 11. 7.
- [찾기 쉬운 생활법령 정리(제27조 면적 비율표)](https://www.easylaw.go.kr/CSP/CnpClsMainBtr.laf?ccfNo=2&cciNo=1&cnpClsNo=2&csmSeq=895)
- [주차장법 시행령 별표 1 (개정 2026. 8. 25.)](https://www.law.go.kr/flDownload.do?bylClsCd=110201&flSeq=168270377&gubun=) — 부설주차장 설치기준
- [주차장법 시행규칙 제6조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=81561) — 차로 높이 2.3m, 직선 램프 17%, 곡선 램프 14%, 연석
- [주차단위구획 2.5×5.0m](https://govbrief.kr/scan/008238/3/)
- 산정표는 `src/parkingRules.js`에 두었습니다. 배율과 면적 기준은 그 파일의 표만 고치면 됩니다.

지자체 조례로 기준이 달라지는 예: [고양시 부설주차장 설치기준](https://www.goyang.go.kr/www/www03/www03_5/www03_5_10/www03_5_10_tab2.jsp). 화면의 할증·완화 비율(기본 1.0)로 반영합니다.

## 도면·현장 표현을 볼 때 참고한 자료

- 노면은 시행규칙대로 흰색 주차선을 쓰고, 차로와 주차면을 색으로 구분했습니다. 국내 지하주차장에서 흔히 보는 에폭시 녹색 차로와 회색 주차면을 그 기준으로 삼았습니다.
- 기둥 하단 노랑·검정 띠, 램프 미끄럼 방지 홈, 입구 높이 제한 바는 현장 사진에서 반복되는 표시입니다. [지하주차장 램프 완화구간 해설](https://dadoplan.tistory.com/23)
- 평면도 표기(기둥 그리드, 치수, 축척, 제목란, 방위)는 건축 평면도에서 쓰는 흰 바탕·검은 선 구성을 따릅니다.

치수 상수는 `src/layout.js` 맨 위에 있습니다. 주차칸 2.5×5.0m, 직각 차로 6m, 직선 램프 17% 이하, 차로 높이 2.3m 이상입니다.

## 2026-11-10 추가 사항

- 장애인전용 구획: 법정 10대 이상이면 2~4%(선택)를 코어 가까이 3.3m 칸으로 배정합니다. `src/stallTypes.js`
- 램프: 지상 램프는 도로변 3m(8.5%, 필수) + 별표 1 완화구간(50대↑ 윗부분 1.7m, 100대↑ 아랫부분 2m)으로 최소 길이를 계산합니다(층고 3.2m·112대 → 21.4m). 지하층 사이 램프는 같은 길이로 쌓고 본 경사를 따로 표시합니다.
- 내부형 램프: 모든 지하층에서 같은 위치. 경사는 외벽에서 11m(외곽 주차줄+순환 차로) 안쪽에서 시작해, 아래층에서 순환 차로를 한 바퀴 돌아 같은 램프로 다시 내려갑니다.
- 내부형 램프: 직선으로 모자라면 반대쪽 순환 차로에서 90° 곡선(내변 6m, 14%)으로 꺾어 이어갑니다. 외부형은 그대로입니다.
- 층고 입력. 유효높이(층고 − 슬래브 0.28m)가 차로 2.3m 이상이어야 생성됩니다.
- 차로가 이어지는 부분까지 전 구간 6m 이상만 연결로 인정합니다.
- 기둥 간격 가로·세로 따로 입력(선택). 예: `4, 5, 6`
- 막다른 차로 정리 · 진입 불가 칸(앞에 차로가 없는 칸) 제외.
- 버그 수정: 비주거 끝수 처리, 최소 이격 0일 때 기둥 겹침 검사.
- three.js를 `vendor/`에 포함해 인터넷 없이도 3D가 뜹니다.
- 자세한 내용과 시험 결과는 `CHANGES.md`, 점검은 `node scripts/stall-types.mjs`.

## 단지형(여러 동 + 지하주차장 1개)

1단계 **건물 형태**에서 `단지형`을 고르면 동 목록(이름·층수·외곽·동 아래 주차 금지)이 나타납니다.

- **법정 주차대수**는 동별이 아니라 **단지 전체 세대수**(공동주택 입력 한 칸)로 계산합니다.
- 동은 위치·지상 층수·외곽(타워)만 갖고, 세대수는 갖지 않습니다.
- 램프는 지금처럼 2차로 6m **1개**를 단지 전체가 공유합니다. 단지형에서는 **내부 램프**가 기본이고, 외부 램프를 쓰려면 해당 변 대지 여유를 램프 길이(약 21m+) 이상으로 두세요.
- 동 3개 이상은 평면 약 **80×58m** 이상을 권장합니다(작으면 평면 생성 시 자동으로 키웁니다).
- **동 코어**(`kind: building`): 승강기+계단, 동에 연결, 3D 타워 매스·도면 라벨에 사용.
- **계단 코어**(`kind: stair`): 피난계단만, 6×4m, 동에 속하지 않아도 됨. 2단계에서 [계단 코어 추가].
- **동 아래 주차 금지(`blockUnder`)**: 켜면 동 외곽 아래에는 주차칸·차로를 두지 않습니다. 끄면 전이(transfer) 구조 안내만 뜹니다.

아직 안 되는 것: 램프 2개(입·출 분리), 비직사각형·사선 모서리 지하 평면, 외부 곡선 램프, 여러 코어 동시 자동 탐색.

점검: `node scripts/multi-building.mjs` (코어 겹침·동 아래 막기·작은 sweep).

## 실행

```powershell
python -m http.server 8765
```

브라우저에서 `http://127.0.0.1:8765/` 를 엽니다.

## Cursor에서 실행하기 (Windows)

1. Cursor에서 **File → Open Folder…** 로 `C:\Users\yuniz\parking-designer-v240` 폴더를 엽니다.
2. **Terminal → New Terminal** 을 열고 아래 명령을 입력합니다. (Python이 없으면 `npx serve -l 8765 .` 도 됩니다.)

   ```powershell
   python -m http.server 8765
   ```

3. 브라우저에서 `http://127.0.0.1:8765/` 를 엽니다. `index.html` 을 더블클릭해서 바로 열면(file://) 모듈 로딩이 막혀 동작하지 않습니다.
4. 코드를 고친 뒤 화면이 안 바뀌면 `Ctrl+F5` 로 새로고침합니다(파일 이름 뒤 `?v=247` 캐시 태그를 올려도 됩니다).
5. 종료는 터미널에서 `Ctrl+C`.

- three.js·Leaflet은 `vendor/` 폴더에 들어 있어 평면·3D는 인터넷 없이도 됩니다.
- 주소 → 용도지역 조회, 주변 매스 지도(브이월드 API·지도 타일)는 인터넷이 필요합니다. 브이월드 키는 `https://dlrldbs0517-cpu.github.io` 로 등록되어 있어 다른 주소에서는 조회가 막힐 수 있습니다.
- 점검 스크립트(Node.js 18 이상): `node scripts/report.mjs`, `node scripts/stall-types.mjs`, `node scripts/sweep.mjs`(1~2분).
